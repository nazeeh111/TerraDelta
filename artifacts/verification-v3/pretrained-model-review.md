## Evidence-backed checks

- **Encoder and BatchNorm freeze.** `pretrained_spatial.py:54–69` requires a complete lowercase SHA, hashes before deserialization, uses `resnet18(weights=None)`, strictly loads the complete state including classifier, then removes only the classifier. Parameters are frozen and the encoder is put in evaluation mode. `:80–96` preserves encoder evaluation mode after outer `train()` and extracts features under `no_grad`. Trainer `:110–111` fingerprints encoder parameters/buffers and passes only decoder parameters to AdamW; `:70–77` verifies parameters, running statistics/counters and absent gradients. An independent test optimizer step left every encoder state tensor unchanged and changed decoder tensors.
- **Decoder-only serialization.** `pretrained_spatial.py:114–131` exports copied CPU tensors from `model.decoder.state_dict()` only, with architecture/backbone/training provenance. It does not export the encoder or optimizer. Test-injected encoders cannot create research checkpoints. `:134–148` requires supported identities and strict decoder loading against a separately SHA-verified backbone. Roundtrip predictions were exactly equal with a random local official-architecture unit checkpoint; wrong SHA and missing classifier keys failed. This unit checkpoint is not a scientific pretrained fit.
- **Native output and masks.** `pretrained_spatial.py:85–111` pads only internally, crops the internal result and averages each native cell's four internal probabilities, returning equivalent finite logits on the original grid. Odd dimensions and tiny dimensions passed. Targets/masks are not resized: shared sampler `train_spatial.py:36–72` transforms RGB/targets/masks together using exact rotations/reflection. Shared loss `spatial.py:81–108` masks both BCE and Dice; entirely invalid masks produce zero loss/decoder gradient. The trainer rejects an entirely invalid actual TRAIN batch (`train_spatial_pretrained.py:118–124`). Invalid pixels can still supply image context, consistent with the existing loss contract; they are not supervision.
- **TRAIN-only pilot.** Trainer `:112` opens only configured TRAIN caches; `:130–147` returns after one masked update, frozen-state audit and `.pilot.json`, before DEV opening at `:149`. The synthetic branch probe replaced cache opening and sampling with random tensors, made DEV sampling/validation/checkpoint creation raise immediately, and confirmed exactly the nine TRAIN IDs were requested. No `.pt` checkpoint was produced. This independently exercises branch order without opening any study arrays.
- **DEV selection and confirmation exclusion.** `require_config` (`:41–63`) checks role sizes 9/4/3, disjointness, old-audit exclusion and configured backbone/resource identity. Main reads DEV only for full fits (`:149–152`), uses the deterministic sixteen-crop helper per region and selects mean footprint/boundary Dice at .5 (`:175–190`; shared sampler `:75–112`). Step0 fallback is explicit; no positive result is required. Configured confirmation IDs appear only in validation/provenance, not cache-opening loops, loss, sampling or selection. There is no old-checkpoint warm-start or resumption route in this trainer.
- **Resource cap and trace.** `:41–50` limits requested updates to at most 4,000 and wall budget to at most 10,800s, with exact batch/scale/crop/thread settings. `:157–205` subtracts initialization/input hashing from remaining time and arms an alarm before DEV selection/updates; `:208–222` additionally checks elapsed time and disarms/restores the alarm. As documented, a running native operation can delay Python's signal handling; the cap is not a hard operating-system kill, and final audit/serialization occur afterward. The separate one-update pilot has no wall alarm, but is a fixed discarded diagnostic update rather than the full optimization loop.
- **Provenance and preservation.** `:95–98` rejects existing checkpoint/trace/pilot paths; best-state writes use atomic replacement. `:153–173` binds TRAIN+DEV RGB/target/edge/valid arrays, cache metadata, config, source, backbone, seed and selection policy. `:226–228` rejects source/config mutation during a full fit.
