    LOCAL DATA INGESTION

    Bring permitted imagery.

    Import a native-grid SpaceNet 7 sequence with the local CLI, then compute its event history before opening this workspace.

    terradelta ingest REGION_DIR --output CACHE_DIR
terradelta run --help

    Use georeferenced RGB/alpha GeoTIFFs with source dates and explicit validity masks. Keep the original coordinate system and source identities. Differing grids require explicit reprojection before ingestion.

    The interface reads the configured local dataset. It does not send your files to a remote service.
